# DAA-LAB

## Design and Analysis of Algorithms Lab

This repository contains the C programs and implementations performed as part of the **Design and Analysis of Algorithms (DAA) Lab**.

The programs cover important algorithmic techniques such as **Divide and Conquer, Greedy Algorithms, Dynamic Programming, Backtracking, Graph Algorithms, and Searching/Sorting techniques**.

---

## Algorithms Implemented

| No. | Algorithm / Problem | Technique |
|---|---|---|
| 1 | Bellman-Ford Algorithm | Dynamic Programming / Graph |
| 2 | Breadth First Search (BFS) | Graph Traversal |
| 3 | Depth First Search (DFS) | Graph Traversal |
| 4 | Dijkstra's Shortest Path Algorithm | Greedy |
| 5 | Sum of Subset Problem | Backtracking |
| 6 | Knapsack Problem | Dynamic Programming / Greedy |
| 7 | Longest Common Subsequence (LCS) | Dynamic Programming |
| 8 | Matrix Multiplication | Divide and Conquer |
| 9 | Merge Sort | Divide and Conquer |
| 10 | Minimum Spanning Tree using Kruskal's Algorithm | Greedy |
| 11 | Minimum Spanning Tree using Prim's Algorithm | Greedy |
| 12 | Travelling Salesman Problem (TSP) | Dynamic Programming / Backtracking |

---

##  Objectives

The main objectives of this laboratory are:

- To understand fundamental algorithm design techniques.
- To implement various algorithms using C.
- To analyze the **time and space complexity** of algorithms.
- To understand the difference between various algorithmic approaches.
- To solve computational problems using efficient algorithms.
- To gain practical experience with graph, sorting, dynamic programming, and backtracking algorithms.
